## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request to search DTO | User query/filter input becomes structured search criteria and must stay bounded. |
| generation document to API response | Local transcript chunks become snippets and highlights; response must not expose raw internals or unbounded text. |
| request path to retrieval provider | FastAPI calls search through lightweight client code and must not import heavy model/index libraries at module load. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Denial of Service | `SearchRequest` | high | mitigate | Preserve query/result bounds and add tests for all new filter bounds. |
| T-04-02 | Information Disclosure | snippets/highlights | high | mitigate | Return concise bounded snippets and normalized scores only; do not expose raw backend score channels or full generation rows. |
