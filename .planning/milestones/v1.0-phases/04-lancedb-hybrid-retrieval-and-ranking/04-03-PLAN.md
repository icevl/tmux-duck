<interfaces>
Hybrid retrieval contract:
- Lexical candidates come from LanceDB FTS or the Plan 01 lexical fallback.
- Semantic candidates come from LanceDB vector search over local Qwen vectors.
- Candidate rows merge by stable `row_id`.
- Explicit filters apply before or during candidate retrieval: runtime, cwd,
  role, content type, status, recent time, window ID, session ID, and pinned.
- Results are grouped by current open `window_id` and bounded by `limit` and
  `hits_per_session`.

Readiness contract:
- Ready search requires active generation metadata plus completed index
  metadata and a healthy retrieval provider.
- Degraded search returns lexical plus metadata results when semantic is
  unavailable.
- Unavailable/not-ready search remains typed when no active index exists.
</interfaces>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| query text to local embedder | User query text enters local semantic model code and must not leave the host. |
| LanceDB candidates to API response | Raw backend scores and rows become bounded user-visible results. |
| index rows to tmux routing | Indexed mutable metadata must be checked against current open sessions before routeable results are returned. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-02 | Information Disclosure | result payload | high | mitigate | Return bounded snippets, normalized scores, match labels, and safe reasons only. |
| T-04-05 | Denial of Service | semantic query path | high | mitigate | On model/vector failure, degrade to lexical plus metadata instead of blocking the app or crashing request handlers. |
| T-04-07 | Spoofing/Tampering | result routing | high | mitigate | Filter/group against current open `window_id` and stale-source records; tests prove closed sessions are hidden. |
| T-04-08 | Tampering | ranking validation | medium | mitigate | Deterministic fixtures cover exact, semantic, repeated, metadata, Codex, and Claude cases before readiness. |
</threat_model>
