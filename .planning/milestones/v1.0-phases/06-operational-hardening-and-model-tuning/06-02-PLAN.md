Harden stale, failed, and degraded search behavior so worker/model/index
failures affect only search while Codi's normal session, chat, Telegram,
terminal, and WebSocket paths remain usable.

Purpose: local search is derived state. It must fail visibly and recoverably
without becoming a global service reliability risk.
Output: stale heartbeat semantics, queue/dead-letter status behavior, lexical
fallback hardening, nonblocking supervisor tests, Web UI degraded labels, and
failure-isolation regression coverage.
</objective>
