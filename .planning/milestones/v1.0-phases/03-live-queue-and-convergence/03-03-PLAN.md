## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| queue lease to generation document write | Leased queue payloads become derived generation documents and must not duplicate or corrupt existing rows. |
| worker drain loop to service lifecycle | Long-running drain work is started from backend lifecycle but must not block Web UI, Telegram, or terminal paths. |
| indexed routing metadata to live tmux state | Result routing metadata is compared with current tmux/session state before normal routeable results are allowed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-02 | Tampering | generation document upsert | high | mitigate | Upsert by stable `SearchRowIdentity`, write temp+fsync+rename, and test duplicate rows collapse to one. |
| T-03-03 | Denial of Service | worker drain retries | medium | mitigate | Bound retries, expire leases by timestamp, and move poison rows to failed/dead-letter state. |
| T-03-04 | Denial of Service | live drain lifecycle | high | mitigate | Supervisor starts live draining asynchronously and shutdown cancels/awaits owned task with timeout. |
| T-03-06 | Information Disclosure | queue failure/status | high | mitigate | Store and expose sanitized error summaries only; preserve existing safe status tests. |
| T-03-08 | Spoofing/Tampering | stale session routing | high | mitigate | Hide documents whose current tmux window/session is no longer open; tests prove dead windows are not routeable. |
