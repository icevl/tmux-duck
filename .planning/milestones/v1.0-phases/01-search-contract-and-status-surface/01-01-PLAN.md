## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | Search API auth | transfer | No endpoint is created in this plan; `01-03` must attach existing `require_auth` and prove unauthenticated requests fail. |
| T-01-02 | Denial of Service | `SearchRequest` | mitigate | Bound `query` to 1..500 characters, `limit` to 1..50, and `hits_per_session` to 1..10 with Pydantic fields and tests. |
| T-01-03 | Information Disclosure | `SearchStatusResponse` | mitigate | Status DTO exposes state, reason, scope, counters, and generation metadata only; no env secrets, raw transcript content, or local transcript bodies. |
| T-01-04 | Tampering | `SearchRowIdentity` | mitigate | Row identity excludes mutable `window_id`, cwd, display name, status, pinned, and sort order; tests prove routing metadata changes do not alter identity. |
| T-01-05 | Denial of Service | request-path imports | mitigate | AST static test rejects heavy model/index/worker imports from `src/codexbot/web/api.py` and lightweight search modules. |
</threat_model>
