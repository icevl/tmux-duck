<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rebuild command to active generation | Local operator command can replace active derived search metadata only after successful backfill. |
| incomplete generation files to status/search API | Request paths must not trust half-written or interrupted generation artifacts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Denial of Service | startup initial backfill | mitigate | Startup schedules work asynchronously and skips rerun when active generation exists. |
| T-02-03 | Tampering | search-owned runtime state | mitigate | All rebuild metadata remains under `CODEXBOT_DIR/search`; tests prove no authoritative state mutation. |
| T-02-04 | Tampering | generation activation | mitigate | Build inactive generation directories and atomically activate metadata only after complete manifest success. |
| T-02-05 | Denial of Service | request-path imports | mitigate | Keep rebuild/worker logic outside `web/api.py` and preserve import-boundary tests. |
| T-02-06 | Information Disclosure | failed rebuild status | mitigate | Sanitize worker/rebuild failures in status and logs; do not expose raw transcript text, secrets, or stacks. |
</threat_model>
