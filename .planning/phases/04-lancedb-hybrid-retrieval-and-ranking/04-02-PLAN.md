<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| transcript chunk to embedder | Local transcript text enters a model provider and must remain local-only. |
| worker batch to LanceDB table | Search worker writes derived rows to a generation-owned table and must not duplicate or corrupt identities. |
| dependency boundary to request path | Heavy model/index libraries exist in the environment but must not slow or break FastAPI imports. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-04 | Information Disclosure | embedding provider | high | mitigate | Use local SentenceTransformer provider only; tests assert no network/client API provider is called and transcript text is not logged in metadata. |
| T-04-05 | Denial of Service | model/index imports | high | mitigate | Lazy-load model/index dependencies inside worker/provider functions and keep request-path import tests. |
| T-04-06 | Tampering | LanceDB row upsert | high | mitigate | Use stable `row_id` derived from `SearchRowIdentity`; tests prove routing metadata changes update one logical row. |
</threat_model>
