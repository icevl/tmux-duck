<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| monitor event to search producer | Live transcript events cross from delivery-oriented monitor code into derived search queue state. |
| transcript replay to queue DB | Worker-owned replay reads local transcript files and writes durable queue rows/watermarks. |
| web server lifecycle to producer tasks | Startup/shutdown owns background listener tasks and must not leak pending tasks on exit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Denial of Service | monitor listener | high | mitigate | Listener schedules brief producer work, catches failures, and tests prove delivery continues. |
| T-03-05 | Tampering | transcript watermarks | high | mitigate | Store watermarks in search queue state keyed by transcript source/offset/index; update only after enqueue success. |
| T-03-06 | Information Disclosure | producer error reporting | high | mitigate | Record sanitized error summaries only; status never exposes raw transcript payloads or secrets. |
| T-03-07 | Denial of Service | web server shutdown | medium | mitigate | Remove listener and cancel/await owned producer tasks with existing web shutdown timeout patterns. |
</threat_model>
