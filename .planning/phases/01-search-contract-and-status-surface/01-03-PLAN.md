<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to FastAPI search API | Untrusted HTTP callers submit search requests and can otherwise discover status unless authenticated. |
| FastAPI route to tmux/session state | Routes read current open-window count for status context without mutating session or monitor state. |
| FastAPI route to search provider | Routes import lightweight provider functions and must not pull model/index work into request handling. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `GET /api/search/status`, `POST /api/search` | mitigate | Both routes use existing `Depends(require_auth)` and tests prove unauthenticated requests return 401. |
| T-01-02 | Denial of Service | `SearchRequest` body | mitigate | Route uses Pydantic `SearchRequest` with bounded query/result fields and tests prove 422 on oversized inputs. |
| T-01-03 | Information Disclosure | route response JSON | mitigate | Tests assert responses omit secret env names, raw transcript content, monitor state filenames, and model/import details. |
| T-01-04 | Tampering | route interaction with session/monitor state | mitigate | Routes read current tmux windows for nullable counters only; provider writes no authoritative state and state tests prove monitor isolation. |
| T-01-05 | Denial of Service | FastAPI imports | mitigate | Route imports only lightweight contracts/provider modules; static AST import-boundary test rejects model/index/worker imports. |
</threat_model>
